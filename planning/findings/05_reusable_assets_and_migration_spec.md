## Minimal migration contract

1. **Raw input.** Read the original archive members. Record dataset revision, member path and SHA-256. Mark placeholders explicitly, keeping their (row, col); never silently drop or keep them.
2. **Frames and time.** Every array carries `frame`, `source_ns`, `sync_id` and `transform_id`. Quaternions are converted by name. Asynchronous stamps are never merged by sync index.
3. **Causality.** Inference gets only allowed inputs that existed before the deadline. Evaluator data (GT, schedules, clean counterparts) lives in a separate store the inference process cannot open.
4. **Interventions.** Deterministic keys; intended/injected/realized ledgers; failures stay in denominators; GT-guided targets are labelled evaluation-only.
5. **Reporting.** Per-segment/session tables; explicit `UNDEFINED`/`CANNOT_ALARM` states; paired clean/attacked comparisons; no IID frame statistics.

D/G tables, A/C/Z values and calibration thresholds are point-cloud statistics. They are **not** latent features, not reliability labels and not GT. Existing point attacks become feature experiments only after the new model path encodes the attacked clouds.
